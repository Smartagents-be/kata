# Shelves

This is the problem for step 1's decomposition task.

## What they asked for

> We would like shelves. A shelf has a name and it holds titles from the catalogue, in the order we
> put them there. We want to make a shelf, put titles on it, take titles off again, open one shelf
> and see what is on it, and see the shelves we have.
>
> A title that is not in the catalogue does not belong on a shelf.
>
> Three of us work the room, so a shelf one of us makes has to be there for the others.
>
> We make a shelf in the morning and fill it during the day, so an empty one still has to exist.
>
> It would help to see the titles nobody has shelved yet, otherwise things get forgotten.
>
> And put a limit on it somewhere. A shelf with two hundred titles on it is not a shelf.
