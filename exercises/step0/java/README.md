# Step 0: the intro

Step 0 is the first thing you meet in the course. It introduces how the course works: how a unit
reads, what a workshop board is, and the loop you will use in every step after this one. The lesson
itself is in the browser; this folder is the small Java project it runs against.

## Where the lesson is

`front/src/steps/step0/`, served at <http://localhost:5173/steps/step0> once the frontend is up.
Start the course there, not here.
