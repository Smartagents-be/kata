There is Java behind this kata, and it is not 1 project. 3 steps have their own under kata/, and kata/step3/java beside them is an empty template: kata/step0/java, kata/step1/java and kata/step2/java, each with its own pom.xml and its own Maven build. Open the folder for the step you are on and run Maven from in there. 2 of them boot a service on port 8080, so only 1 runs at a time. Start the second while the first is still up and the boot fails on the port rather than on anything you did.

The exercises run against that code. A unit points you at a job in its own step's project, and doing it puts the flag within reach: sometimes the build prints it, sometimes your agent has to go and find it. Watch out for red herrings from the last page of this step on: a string in braces is not always the one you are after.

Code blocks

Some pages hand you a code block, like the one below. Give it to your agent to run rather than pasting it into a terminal yourself. House rule 1 is the reason, and this is the cheapest place in the course to start keeping it. Nothing in the build checks which of you ran it. 

cd kata/step0/java
mvn verify -Pintro

The next page puts 3 of those runs on the platform, and this block is the first of them.
