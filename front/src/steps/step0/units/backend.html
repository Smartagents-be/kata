The pages you are reading are only half of the kata. There is also a Java backend, split by step, that you run with Maven on your own machine.

When a step does, the answer box still grades in your browser, the same salted check you just saw. What changes is where the code comes from. You run the backend, it prints the code, and you paste that in. So an exercise can hand you nothing on the page and still be gradable offline.

Code blocks

Sometimes you find code blocks in the course, like the one below. They are indicative: they show how you could run the code yourself. You will also be able to instrument this through your AI agent, by giving the agent the job of running something for you. 

mvn verify -Pintro
