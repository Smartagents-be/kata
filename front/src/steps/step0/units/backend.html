Each step with Java has its own project: exercises/step0/java, exercises/step1/java and exercises/step2/java. Open the folder for the step you are on and run your Maven commands from there.

In the exercises you work in that step's project. Sometimes the build prints the flag, sometimes you have your agent find it. From the last page of this step on, not every string in braces is the flag you are after.

Code blocks

Some pages hand you a code block, like the one below. Give it to your agent to run rather than pasting it into a terminal yourself. House rule 1 is the reason, and this is the cheapest place in the course to start keeping it. Nothing in the build checks which of you ran it. 

cd exercises/step0/java
mvn verify -Pintro
