There is also a Java backend, and it is not one project. Every step has its own under kata/, so kata/step0/java, kata/step1/java and so on, each with its own pom.xml and its own Maven build. Open the folder for the step you are on and run Maven from in there. The ones that run a service boot on port 8080, so only one of them runs at a time.

That code is what the exercises work against. A module can point you at a job to do in its own step's project. Do it right and a flag becomes available. From step 1 on, watch out for red herrings: a string in braces is not always the one you are after.

Code blocks

Sometimes you find code blocks in the course, like the one below. It matters that you use them and drive them through your AI agent, or the flag will not show up. 

cd kata/step0/java
mvn verify -Pintro

Step 1 opens on tokens, which is what everything you send an agent is counted in.
