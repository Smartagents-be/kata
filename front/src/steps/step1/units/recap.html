This step was about 3 things: what fits in the window, what a session costs, and where an answer comes from. They are related, but they are not the same.

What it costs, and what to do about it

  • Text is counted in tokens, and logs full of ids take many. Paste only the part of a log that matters .
  • Every follow-up sends the context again, and reasoning is billed as output. Bundle related changes into 1 request .
  • An unused tool can still take up context. Turn off the ones this task does not need .
  • Old versions and dead ends stay in the window. Check the current file, and clear between unrelated tasks .
  • Everything in your session counts as input on every turn while it stays in the window. Ask your follow-ups while the code is in front of you, then clear once the problem is closed .
  • The harness caches the start of each request. Pick your model and effort before you begin, so the cache keeps working .
  • Model choice sets the price and what the model can handle. Try a cheaper model on a well-defined task, and check the result .
  • An answer sounds the same whether the agent read your file or filled the gap. Ask for a test that can go red, and look a package up before you add it .
  • Claude’s 5-hour and weekly limits are separate from the context window. Check both before you start a long run .
  • On a company seat, Copilot draws AI credits from a shared monthly pool. A budget your admin sets can stop the agent mid-task, so check your usage before a long run .
