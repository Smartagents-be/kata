Notes written down on purpose in one session so they come back in the next one. Memory is the only layer that survives a /clear, because something decided it was worth keeping.

That makes it useful and also makes it the layer most likely to be quietly out of date. A note saying "this project has no Maven wrapper" stays true until the day somebody adds one.

Exercise

You type /clear and keep working in the same repository. Which of these is still in front of the agent afterwards? Answer keep or gone for each item, comma-separated, in order.

  1. The output of the mvn test run from earlier in this chat.
  2. The "Conventions" section of this repo's CLAUDE.md.
  3. A note you asked the agent to remember last week.
  4. The prompt you typed three turns ago.
  5. The description of the Read tool.

Two of these are gone. Everything else comes back on its own, either because the agent reads it out of the repository again or because it was there before you typed anything.
