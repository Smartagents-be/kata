Zet bij elk item hieronder de laag waar het vandaan komt. De labels zijn prompt, session, project, harness, memory en external. Je typt ze in het Engels, want de Java-service kijkt ze zo na. Geef de acht labels gescheiden door komma's, in volgorde.

  1. De zin die je net getypt hebt.
  2. De sectie "Conventions" uit de CLAUDE.md van deze repo.
  3. De beschrijving van de tool Read, die zegt dat de agent bestanden mag openen.
  4. Jouw "nee, gebruik AssertJ" van twintig berichten geleden.
  5. Release notes van Spring Boot die de agent van het web gehaald heeft.
  6. Een notitie van vorige week, "dit project heeft geen Maven wrapper", vandaag opnieuw geladen.
  7. De uitvoer van de mvn test die de agent eerder in dit gesprek gedraaid heeft.
  8. De branch waarop je zit en de laatste vijf commits.
Notities

Items 4 en 7 lijken project te zijn. Items 2 en 8 lijken session te zijn. Eén vraag scheidt ze: staat dit er na een /clear nog?

Een testrun bestaat alleen omdat hij in dit gesprek gebeurd is. Wis de sessie en hij is weg. CLAUDE.md en de git-historie horen bij het project, dus een gloednieuwe sessie pikt ze vanzelf weer op.

Item 3 verraadt harness. Niemand heeft het getypt, het staat niet in de repo, en toch weet de agent het al voor jouw eerste bericht.

Voor je indient, toont je lesgever een live sessie: wat er nu in het venster zit, wat compactie ermee doet, en wat een /clear overleeft.
