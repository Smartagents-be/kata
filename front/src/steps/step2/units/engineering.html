Good agentic projects start with good software engineering. That is the whole line between vibe coding and agentic engineering.

Vibe coding is asking for a feature, skimming what comes back, and running it. When it breaks you paste the error and say "fix this". That works for about an hour. Then the fixes start breaking each other. The loop feels productive right up to the moment you cannot answer a simple question about your own repository.

Software engineering has always been a craft. A problem arrives from the business, you break it down until each part is small enough to be sure about, and you pour the result into a process that runs as code. None of that changes when an agent does the typing.

Domain-driven design

Folders and classes carry the names the business uses. Headline is a headline and article/ is where articles live. Ask for a feature on articles and your sentence has already named the files

That is a bigger lever with an agent than it ever was with a team. A model reads your repository as tokens and predicts what comes next. Step 1's unit on tokens showed it predicts plain English best. The names in your tree are half of every prompt you write against it.

Hexagonal architecture

The domain sits in the middle, the machinery lives behind adapters, and the direction of a call is a folder you can point at. No class outside adapter/ names Postgres or S3, so swapping the database out is one folder's work.

What that saves with an agent is the search. It opens application/ for a use case and adapter/outgoing/ for the thing that talks to S3, instead of reading half your repository into the window first .

The right words

Name the thing you want. "Put a repository in front of this JDBC call" lands somewhere specific. "Clean this up a bit" lands in the statistical middle of every cleanup ever written. Design pattern names, layer names and the vocabulary of your domain are compression. The agent has less to guess That is also what separates an app built in half a day from one you can put in production.
